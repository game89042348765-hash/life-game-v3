# LifeGame v3.0.2 — Пакет публикации для GitHub Pages (`life-game-v3`)

## Что добавлено в v3.0.2
- **Внеэкранный живой спутник (`companion-avatar.js`)**: 5 философских архетипов в читаемой не-чёрной палитре (`Путник`, `Живой Очаг`, `Росток Древа`, `Кинцуги`, `Хранитель Курса`), 5 состояний (`Налегке`, `Доспех Pro`, `Мобилизация: устал на 5-й день`, `Жмём дальше!`, `Отдых`) и несгораемая эволюция по уровням `XP` (`Ур. 4` звезда, `Ур. 8+` ореол).
- **Двухслойная база `companion-db.js` v2**: примерочная 3 спокойных режимов в **День 1**, знакомство с **Мобилизацией** в **День 7**, 14 карточек смыслов и 8 живых ситуативных развилок `Да / Нет` (включая честный вопрос напарника на 5-й день Мобилизации).
- **Лёгкая замена графики**: вся визуальная отрисовка вынесена в отдельный файл `companion-avatar.js` (плюс прямо в Настройках есть кнопка `📎 Загрузить свой лист 1×5` для живой примерки новых картинок).
- **Автообновление кэша**: `sw.js` переведён на `lifegame-v3.0.2` — все сохранения в `localStorage` остаются нетронутыми.

## Как выложить обновление
Распакуй содержимое архива в корень ветки `main` репозитория `life-game-v3` с заменой файлов.
