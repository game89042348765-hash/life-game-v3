# LifeGame 3.0 — Пакет публикации для GitHub Pages

Эта сборка возвращает чистоту и простоту первой версии приложения:
- **Основа системы**: `Блоки времени` и `Этапы` (`Текущий этап` / `Все этапы`, карточки Смысла `#302023` и Целей `#1D2D25` с планом «Если — то» и правом отказа без штрафа).
- **Дополнение**: `Карта жизни` открывается только по желанию кнопкой `🗺 Карта-обзор` внутри раздела `Блоки`.
- **Постепенное раскрытие**: переключение в 1 касание между `Базовым` (простой день без нижних вкладок) и `Полным` режимом (`Главная · Блоки · Квесты · Бонусы`).
- **Обновление кэша**: новый `sw.js` (`lifegame-v3.0.0`) автоматически сбрасывает старый кэш `v2.0` у посетителей GitHub Pages.

## Как обновить репозиторий GitHub Pages
Загрузи содержимое этого архива прямо в корень ветки `main` репозитория `life-game-model-karbon` (чтобы `index.html`, `app.js`, `sw.js` и папка `fonts/` лежали прямо в корне).
